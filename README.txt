LV SERVIÇOS — V2
- Abra index.html para testar.
- Para instalar no Android: publique a pasta em hospedagem HTTPS; abra no Chrome; toque em “Instalar” ou no menu ⋮ > “Adicionar à tela inicial”.
- O app salva documentos no navegador do dispositivo.
- Para PDF, use “Salvar PDF” e escolha “Salvar como PDF”.
- O WhatsApp abre uma mensagem pronta; anexe o PDF salvo.
- Para publicar: GitHub Pages, Netlify, Vercel ou hospedagem própria.
